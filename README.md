# DesignPortfolio

> A humble portfolio of a humble designer.

I started working on this project with two goals in mind: to create a dedicated space to showcase my design work, and to build a website entirely from scratch, typing every single line of code myself.

It took me just two days to produce the initial version (excluding later updates), and I am incredibly proud of it, especially considering I learned everything in less than two weeks through [The Odin Project](https://www.theodinproject.com/). 

While I know it is a simple project, I am genuinely glad I built it.
